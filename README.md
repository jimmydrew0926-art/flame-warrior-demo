# 烈焰战神：极速变形 · 免费试玩版

这是一款 2D 横版闯关小游戏，包含第一关「未来城市：极速突围」。支持电脑键盘和安卓、iPhone 浏览器触屏操作，手机建议横屏游玩。

点击「启动引擎」开始。左侧圆盘摇杆控制左右移动；右侧分为加速、变形、跳跃的动作组，以及激光剑、火焰炮、导弹、冲击波的武器组。左右控制区之间保留空白，方便双手握持。可以同时按住摇杆和动作按钮；机甲武器可以按住连续攻击。

浏览器地址栏收起或展开、可见画面高度变化时，持续按住的摇杆或按钮不会中断。横竖屏旋转会释放旧的触屏输入，请在新方向重新按住控制。顶部暂停按钮可以暂停或继续，切到其他应用时游戏会自动暂停。

## 第一关

驾驶金黑色跑车穿过未来城市，跳过路障和断桥，收集齿轮与能量水晶。遇到机器人封锁时变形成机甲，击毁守卫解除封锁。最后击败两阶段城市守卫 Boss，再拾取第一枚能量核心即可通关。

绿色补给修复生命，蓝色水晶增加冲击波能量；关卡中还有隐藏奖杯和武器零件。死亡后可以从检查点重新开始。进度保留在当前页面会话，刷新页面会重新开始。

本试玩版只包含第一关；通关后的「沙漠峡谷已解锁」是后续章节提示。

## 使用与 GitHub Pages 发布

电脑可直接打开 `index.html` 游玩。安卓浏览器或 iPhone Safari 可打开[正式免费试玩网页](https://jimmydrew0926-art.github.io/flame-warrior-demo/)，建议横屏。

创建公开的 `flame-warrior-demo` 仓库后，将本目录全部文件上传到 `main` 分支的根目录，确保 `index.html` 直接位于仓库根目录。

在仓库 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**，分支选择 **main**、目录选择 **/ (root)**，然后保存。待发布完成，以 GitHub Pages 设置页实际显示的地址为准。

发布后可用安卓浏览器或 iPhone Safari 打开网页，横屏检查摇杆、跳跃、变形、同时移动与攻击，以及暂停和检查点重启。
